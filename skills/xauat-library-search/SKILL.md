# 西建大图书馆论文检索

## 全局触发

当用户要求查找论文、核对文献、筛选期刊、补充综述证据、寻找全文或核对 DOI，且未明确指定其他检索平台时，优先调用本技能。用户说“去图书馆查”“打开学校数据库”“在我的图书馆找论文”也属于本技能。

本技能适用于所有使用当前用户级 Codex skills 的对话。它通过浏览器会话访问学校平台，不是公开 API。

## 固定入口

优先复用用户已经打开的夸克浏览器标签页和登录会话；如果夸克未提供可接管的会话，再使用 Edge 或其他已登录浏览器：

- 图书馆首页：<https://lib.xauat.edu.cn/index>
- 统一检索平台：<https://lib.xauat.edu.cn/scenemanage/web_library>
- 统一检索结果页：<https://lib.xauat.edu.cn/articlesearch/web_searchingResult?high=h>

如果用户要求“打开图书馆”，先打开首页；如果用户要求检索论文，直接进入统一检索平台或已打开的检索结果页。

需要外文高质量期刊时，可从学校数据库导航或用户已打开的代理标签页进入：

- Springer Nature Link 高级检索：<https://libresource.xauat.edu.cn/https/443/com/springer/link/yitlink/advanced-search>
- Web of Science Core Collection：从学校数据库导航进入 Clarivate/WOS 代理。

WOS、Springer 和统一检索页面都属于同一浏览器会话。优先复用现有标签，不重复登录。

## 浏览器会话规则

- 不读取、保存、复制或索要账号密码。
- 用户明确指定夸克浏览器时，优先在夸克中完成导航和检索；不得擅自切换到内置浏览器替代已登录会话。
- 如果出现统一认证、验证码、二次验证、机构访问确认或下载授权，停止自动操作，请用户在浏览器中手动完成。
- 不绕过付费墙、机构认证、验证码或下载限制。
- 只进行用户要求的检索、核对和结果整理；不修改收藏、检索历史、账户设置或下载任务，除非用户明确要求。
- 用户明确要求下载论文时，可以下载公开可访问或学校会话已授权的文件；遇到授权或验证码时交给用户完成。

## 检索流程

1. 提取关键词、布尔关系、年份范围、文献类型、语言和数据库要求。用户没有限定时，不擅自增加年份、数据库或文献类型限制。
2. 在检索页清除旧查询，输入本次检索式；优先使用页面提供的高级检索和筛选项，不猜测未显示的字段含义。
3. 记录实际提交的检索式、筛选条件、命中数和检索日期。
4. 打开候选结果详情页，核对题名、作者、期刊、年份、卷期页码、DOI、摘要、数据库标识和全文入口。
5. 返回结果时默认使用表格列出：题名、作者、期刊/年份、DOI或稳定链接、馆藏/全文状态、与用户问题的相关性。
6. 没有 DOI 时明确写“页面未提供 DOI”，不得补猜。
7. 需要综述证据时，额外标注研究对象、预处理或浸出阶段、结构表征、目标元素释放、杂质迁移和证据边界。区分“检索到”“已核对书目信息”和“已核读全文”。

## 查询表达

- 中文、英文和化学式可以并列使用。
- 固定短语用引号；多个概念用页面支持的 AND/OR 关系连接。
- 用户给出作者、年份、题名片段或 DOI 时，先用这些信息定位，再核对详情页。
- 用户只说“帮我找论文”而没有主题时，先询问最小必要信息，不盲目检索。

## 学术证据边界

- 图书馆检索结果用于发现和核对文献，不自动等同于论文原文证据。
- 不能仅凭列表摘要推断全文可得性、索引状态或研究结论。
- 需要支持学术论断时，继续打开可访问原文或让用户提供 PDF，并明确证据来源。
- 不把“检索命中”写成已经证明的机制；分别标明作者结论、直接表征和综述推断。
