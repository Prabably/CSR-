# CSR review project lessons

Use this file together with `PROJECT_DECISIONS.md` and `REVISION_LOG.md`. The files preserve different kinds of information: lessons explain how to work, decisions record what has been agreed, and the log records what changed.

- Apply the lowest user-authorized edit level. A request to change a citation number is an L0 exact replacement and must not alter the surrounding prose.
- Keep the paragraph's central claim visible after compression or polishing. Do not replace a clear argument with generic mechanism language.
- The CSR review should explain how selectivity forms, is amplified, and is maintained across resource state, pre-leaching solid control, leaching and liquid species, separation, and productization.
- Preserve representative real-resource cases and quantitative evidence when they carry an argumentative role.
